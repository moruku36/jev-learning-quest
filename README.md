# Jev 学習クエスト (Jev Learning Quest)

判断AI **Jev** が「今日やる1つ」を選んでくれる、個人用の学習アプリです。
**情報処理安全確保支援士の試験対策**と、**AI・クラウド・セキュリティの技術キャッチアップ**を、短い時間でも迷わず続けられるように作っています。

```
使える時間と気分を選ぶ → Jev がクエストを1つ提案 → 解いて自己採点 → Jev が理解度と復習の要否を判定
```

---

## 3ステップで始める

### 1. 起動する

Node.js v18 以上（v22 推奨）があれば、`npm install` は不要です。

```bash
npm start
```

ブラウザで **http://localhost:3000** を開きます。

### 2. Jev の APIキーを入れる

1. 画面右上の **「Jev 未設定」** か、ホームの **「APIキーを設定する」** を押す
2. APIキーを貼り付けて **「保存して接続テスト」** を押す
3. 「Jev に接続できました」と出れば完了です。右上が **「Jev 有効」** になります

- 無効なキー（認証エラー）は保存されません。
- キーは設定画面からいつでも差し替え・削除できます。
- **キーを入れなくても、アプリ内ルールで全機能を使えます。**

### 3. 学習する

- **今日のクエスト**: 使える時間（10〜60分）・分野・今日の気分を選ぶと、Jev がクエストを1つ提案します。気に入らなければ「ほかの候補を見る」から変更できます。
- **復習**: できなかった問題は数日後に再挑戦クエストとして出題されます。正解すると「克服済み」になりリストから消えます。
- **素材を登録**: 支援士の過去問（出典と設問）や、技術記事（次の行動つき）を登録します。

---

## Jev がやること

Jev は文章を生成せず、次の **判断だけ** を行います。

| 判断 | タイミング | 内容 |
| :--- | :--- | :--- |
| **Choice** | クエスト提案時 | 候補の中から今日のクエストを1つ選ぶ |
| **Score** | 結果の保存時 | 答案とメモから理解度を4段階で判定 |
| **Noul** | 結果の保存時 | 数日後に復習すべきかを判定 |

画面上のバッジで、判断した主体が分かります。

- 🧠 **Jev が選定** … Jev が判断
- 📋 **ルールで選定** … キー未設定のためアプリ内ルールで判断
- ⚠️ **Jev 接続失敗 → ルールで選定** … Jev に接続できず、ルールに自動で切り替え

Jev の確信度は内部の判断材料としてのみ使い、正解率としては表示しません。

## APIキーの扱い

| 方法 | 使いどころ |
| :--- | :--- |
| **画面から入力**（おすすめ） | 設定画面で保存。`data/config.json` に保存され、再起動後も有効 |
| **環境変数 `JEV_API_KEY`** | サーバーやスクリプトで起動する場合。画面の設定より優先 |

```powershell
# PowerShell の例
$env:JEV_API_KEY="your-jev-api-key"
npm start
```

- キーはサーバー側だけで使い、ブラウザには `jev_••••1234` のようなマスク表示しか返しません。
- `data/config.json` は `.gitignore` 済みで、バックアップファイルにも含まれません。
- サーバーは既定で `127.0.0.1`（このPC）からのみ接続を受け付けます。他の端末から使う場合は `HOST=0.0.0.0` を指定してください（キーを扱うため、信頼できるネットワークでのみ）。

---

## データ

- 学習データは `data/store.json` に保存されます（初回起動時に自動作成）。
- 設定画面から **バックアップのダウンロード / 復元**、**サンプルの追加 / 削除** ができます。
- 過去問本文は著作権保護のため同梱していません。出典と設問を自分で登録してください。
- 同梱のサンプルデータはすべて架空のもので、タイトルに【サンプル】と付いています。

## 環境変数

| 変数 | 既定値 | 説明 |
| :--- | :--- | :--- |
| `PORT` | `3000` | 待ち受けポート |
| `HOST` | `127.0.0.1` | 待ち受けアドレス |
| `JEV_API_KEY` | なし | Jev APIキー（設定すると画面の設定より優先） |
| `LQ_DATA_DIR` | `./data` | データの保存先フォルダ |
| `JEV_API_URL` | `https://api.typesafe.ai/v1/systemone` | Jev API のエンドポイント（テスト用） |

## 開発

```bash
npm test
```

一時フォルダとモックの Jev API を使ってサーバーを起動し、次を自動で検証します（実データや本物の Jev API には触れません）。

- キー未設定でもルールで動作すること
- 素材の登録、クエスト推薦、誤答からの再挑戦、再挑戦成功での克服済み化
- APIキーの保存・マスク表示・削除、無効なキーのエラー表示、キー保存後の Jev 判定
- バックアップにキーが含まれないこと
- JSON 以外の POST の拒否、CORS 無効、`public/` 外のファイルを配信しないこと
