# 今日の学習クエスト (Today's Learning Quest)

個人用の学習・技術キャッチアップWebアプリケーションです。  
限られた時間でも、**情報処理安全確保支援士の試験対策**と、**AI・クラウド・セキュリティ分野の継続的なキャッチアップ**を両立し、「今日何をするか」「理解できたか」「次に何を復習するか」を迷わず進められるように設計されています。

---

## 主な特徴

1. **今日のクエスト提案（迷わず着手）**
   - 利用可能時間（10分・20分・30分・60分）、対象分野、今日の気分・目的に応じて最適な1クエストを提示。
   - 作業内容・所要時間・選定理由・完了条件が明示され、別の候補への変更もワンクリック。
2. **判断特化型AI「Jev」の活用と耐障害性**
   - Jevを文章生成ではなく「判断（Choice: 候補選定 / Score: 理解度判定 / Noul: 復習要否）」にのみ使用。
   - Jevの確信度・確率は正解率としては表示せず、内部の判断材料として活用。
   - `JEV_API_KEY` 未設定時やAPI失敗時も、アプリ内固定ルールベースエンジンが自動稼働。画面上で判定元（Jev vs ルール）をバッジで明確に区別。
   - APIキーはサーバー側の環境変数からのみ読み込み、ブラウザ通信・ログ・リポジトリには一切出しません。
3. **支援士モード（科目B対策・弱点克服）**
   - 過去問を解く前に解説は見せません。
   - 設問文、自分の答案、所要時間を記録。
   - 正誤だけでなく誤答原因（「読み落とし」「知識不足」「設問要求とのずれ」「時間不足」など）を記録。
   - 誤答した問題は、数日後に解説を隠した状態で「再挑戦クエスト」として最優先提案。
   - ※著作権保護のため過去問本文は同梱せず、ユーザーが出典と設問を登録する方式。
4. **技術キャッチアップモード（次の行動1点付き）**
   - AI、クラウド、セキュリティの更新情報・記事を登録。
   - 「読んだ」で終わらせず、各項目に「試す」「設定を確認する」「既存知識と比較する」「チーム向けに説明する」のいずれか1つの次アクションを必須付与。
   - 架空の更新情報を自動生成することはせず、登録された確実な情報のみを扱います。
5. **永続化とバックアップ**
   - 外部DB不要（ゼロ依存）。ローカルJSONファイルにアトミック保存。
   - 初回起動用の架空サンプルデータ（明記済み）を用意。ワンクリックで削除・再投入可能。
   - バックアップJSONのエクスポート／インポート対応。

## 起動方法

### 前提環境
- Node.js v18 以上 (v22 推奨)
- 外部パッケージのインストール (`npm install`) は不要です（Node.js標準ライブラリのみで動作）。

### 1. サーバーの起動 (キー未設定で即座に動作)
```bash
# プロジェクトディレクトリに移動
cd C:\Users\kentaro\.gemini\antigravity\scratch\todays-learning-quest

# サーバー起動 (デフォルトポート: 3000)
npm start
# または
node server.js
```
ブラウザで `http://localhost:3000` にアクセスします。

### 2. Jev API キーを設定する場合 (任意)
Jevの判断モデル（`POST https://api.typesafe.ai/v1/systemone`）を利用したい場合は、環境変数 `JEV_API_KEY` を設定して起動します。

#### PowerShell:
```powershell
$env:JEV_API_KEY="your-actual-jev-api-key"
node server.js
```

#### コマンドプロンプト (cmd):
```cmd
set JEV_API_KEY=your-actual-jev-api-key
node server.js
```

> **注意:** キーが未設定、またはAPI呼び出しが失敗した場合でも、完全なルールベース提案に自動で切り替わるため、すべての機能をそのまま利用できます。

## データの保存先
- **保存先パス:** `data/store.json`
- サーバー起動時に自動生成されます。
- アプリを終了・再起動しても学習記録や登録した素材は保持されます。
- 画面上の「設定」タブからいつでもJSON形式でバックアップのダウンロードおよび復元が可能です。

## 確認した動作 (検証済み項目)

自動検証スクリプト (`node test_verification.js`) および手動起動にて以下の動作を確認済みです：

1. **JEV_API_KEY 未設定での起動・操作**:
   - キー未設定時も警告なく起動し、ステータス画面で「ルールベース動作」と認識されることを確認。
   - 過去問・キャッチアップ素材の登録、クエスト推薦、実行、自己採点、履歴保存の全フローが完了することを確認。
2. **再起動後のデータ永続化**:
   - 登録した支援士問題、キャッチアップ記事、および実行履歴が `data/store.json` に保存され、再起動後も正しく読み込まれることを確認。
3. **支援士の誤答からの再挑戦クエスト自動生成**:
   - 過去問演習で「誤答（設問要求とのずれ／知識不足）」を記録すると、数日後の復習対象として認識され、ホーム画面で最優先の「誤答を直す（再挑戦）」クエストとして推薦されることを確認。
4. **技術情報キャッチアップの出典と次の行動**:
   - 記事登録時に「出典」と「次の行動（試す／設定を確認する等）」が必須記録され、クエスト実行時に具体的な作業指示として表示されることを確認。
5. **Jevキー設定時の挙動と安全なフォールバック**:
   - キー設定時にJev APIエンドポイントへのリクエストを行い、通信エラーや認証エラー発生時にもアプリが停止せず、即座にルールベース提案へフォールバックすることを確認。
   - 画面上のバッジ（`[Jev判断 (Choice)]` / `[ルールベース提案]`）で選定元が正確に区別されることを確認。

## 画面構成

| 画面 | 概要 |
| :--- | :--- |
| **ホーム** | 今日のクエスト提案、利用可能時間（10/20/30/60分）・分野・気分の選択、直近進捗サマリー、候補一覧モーダル |
| **クエスト実行** | 作業内容・設問文（解説なし）、カウントダウンタイマー、答案入力、自己採点、誤答原因分析（読み落とし/知識不足/設問要求のずれ等）、Jev Score/Noulまたはルールによる理解度判定 |
| **学習記録** | 再挑戦待ちリスト（ワンクリックで再演習開始）、誤答原因の集計分析、過去の演習履歴テーブル |
| **情報登録** | 支援士過去問登録（出典・設問・ポイント）、技術キャッチアップ登録（タイトル・URL・実務価値・次の行動1つ） |
| **設定** | Jev接続状態インジケーター、架空サンプルデータ管理（再投入／実データのみ残して全削除／全初期化）、データバックアップ（エクスポート／インポート） |
