Jev API 接続状況

確認中...

Jevの役割と設計思想:

  • 文章生成は行いません: Jevはテキスト生成ではなく「Choice（候補選択）」「Score（理解度判定）」「Noul（復習要否真偽）」の3つの判断プリミティブのみに利用されます。
  • 確信度の扱い: Jevの出力する確率は内部の選定判断のみに用いられ、ユーザーの学習正解率として誤認表示することはありません。
  • セキュリティ: JEV_API_KEY はサーバー環境変数でのみ読み込み、画面やクライアント通信、ログ、リポジトリには一切露出しません。
  • 未設定・失敗時の耐障害性: キー未設定時やAPI通信エラー時は、アプリ内のルールベースロジックへ自動フォールバックし、通常通り利用を継続できます。
