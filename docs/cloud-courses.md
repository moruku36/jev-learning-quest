# AWS・GCP の資格別一問一答

2026-10-22 に公式の資格ページと公開試験ガイドを確認し、その領域に沿って独自に作成した日本語の想起練習です。公式試験問題、非公開問題、公式サンプル問題の転載ではありません。短い一問一答なので、実試験の選択式問題やケーススタディの判断力を測るものでもありません。出題領域や製品名は今後更新されるため、受験前にはリンク先の現行ガイドを確認してください。

| 分野 | 表示順 | 対応する現行資格 | 問題数 | 公式ガイド |

Google Cloud の資格ページは [Generative AI Leader](https://cloud.google.com/learn/certification/generative-ai-leader)、[Cloud Digital Leader](https://cloud.google.com/learn/certification/cloud-digital-leader)、[Associate Cloud Engineer](https://cloud.google.com/learn/certification/cloud-engineer)、[Professional Cloud Architect](https://cloud.google.com/learn/certification/cloud-architect)。GCP はアプリの分野名として用い、資格の公式名称はコースカードに表示します。Google Cloud の一部ガイドでは旧称 Vertex AI に対応する製品が **Gemini Enterprise Agent Platform** などの名称で記載されています。問題文は確認時点のガイド表記を使います。

AWS AI Practitioner は公開ガイドの5領域（AI/MLの基礎、生成AIの基礎、基盤モデルの応用、責任あるAI、AIのセキュリティ・コンプライアンス・ガバナンス）に対応します。Google Cloud の基礎AIは4領域（生成AIの基礎、Google Cloudの製品、出力改善、導入戦略）です。Cloud Digital Leader は6領域、Associate Cloud Engineer は4領域、Professional Cloud Architect は標準試験の6領域に対応します。上級の30問は用語と短い状況判断であり、Professional Cloud Architect の実試験に含まれるケーススタディは再現しません。

問題IDは一度公開したら変更しない前提です。進捗は問題IDごとに保存され、AWS・GCP・IPAの集計を分けています。クラウド資格の問題は端末のオフライン用問題キャッシュには入れず、オンライン時に出題します。「答えを見る」までは回答を隠し、自己判定後に次問へ進みます。設問や根拠に誤りを見つけた場合はアプリの「この問題おかしい？」から報告できます。
