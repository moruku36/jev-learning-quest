# Weekly reading list updates

## English

The Monday workflow remains on its existing schedule: 00:00 UTC (09:00 JST). Each run may add up to eight eligible readings. It removes no more existing readings than it adds, and it keeps the current list unchanged when no eligible candidates are available. A shortfall is reported with added, removed, retained, and source-failure counts.

RSS candidates need a real, non-future publication date and must be no more than one year old. Existing URLs and titles are deduplicated. Publication dates are retained in the catalog; the updater does not substitute the run date when a feed omits one.

Conference material is curated from a first-party abstract or paper with an official URL and conference dates. The event program or date alone is not a reading. At most three conference-abstract items from the same evidence class are selected in one run so conference signals do not crowd out other current research. Conference work is a technical leading signal, not evidence of incident prevalence; compare it with incident and breach reports.

## 日本語

月曜の週次workflowは既存どおり00:00 UTC（日本時間09:00）に実行します。1回に追加する教材は最大8件です。削除数は追加数を超えません。適格な候補がなければ現在の一覧を維持し、追加・削除・保持・情報源の取得失敗数と不足理由を出力します。

RSS候補には実際の公開日が必要です。未来日付と1年以上前の候補は除外し、既存のURL・題名との重複も除きます。公開日は教材データに保持します。RSSに日付がない場合に実行日を代入することはありません。

カンファレンス教材は、公式URLと開催期間を確認でき、主催者または発表者による要旨・論文を読めるものに限ります。開催案内や日程だけのページは教材にしません。同じ種類の会議要旨は1回に最大3件とし、他の新しい研究を押しのけないようにします。会議発表は技術上の先行シグナルであり、実被害の発生率を示す統計ではありません。インシデント・侵害統計と照らして読みます。
