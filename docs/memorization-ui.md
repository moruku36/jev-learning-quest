# 暗記のための学習画面

- 通常の一問一答は回答・自己採点後も正解を表示し、「次へ」を押すまで進まない。間違えた理由もこの間に選べる。
- 完了後はその回の誤答だけを再挑戦できる。再挑戦は保存しない練習で、最初の履歴と翌日の復習予定を変えない。
- NWは原本画像を画面内で100〜300%に拡大・縮小。スクロール、幅合わせ、ページ切替、画像失敗時の案内がある。
- NW午前の回答・公式正解を採点時と保存後の両方で表示。完了後の同問題再挑戦も保存しない練習。
- 解説が未収録の教材は未収録と明示する。正解キー・教材本文を推測で書き換えていない。
- 5分の学習枠に45分・120分のNW復習を推薦しない。
- 通常の四択は他カードの答えから作る練習選択肢であり、IPA公式選択肢ではない。NW午前は公式原本の選択肢と公式キー。

## 検証

既存 `npm test` に短時間推薦の回帰を追加。`npm run check` は構文確認（lint/build設定は元からない）。
GitHub Actionsで `node test_learning_ui.js` をChromium上で実行。375px/1280pxの実画面とローカルAPI・一時保存先で、正解表示、自己採点後停止、連打、再挑戦時の履歴不変、NW画像拡大、ページ切替、画像失敗案内を確認する。スクリーンショットはActionsの learning-ui-evidence artifact。

クラウドの認証・RLS・資格情報・アクセス制限・費用設定は変更しない。公開デプロイとの差の確認は別途必要。
