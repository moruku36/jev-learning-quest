# AWSコースと旧分野の整理

## 変更の概要

- 分野は「ネットワーク（`nw`）」「支援士（`sc`）」「AWS（`aws`）」。旧分野の AI（`ai`）・クラウド（`cloud`）・セキュリティ（`security`）は、学習画面の分野一覧・読み物・おすすめ・復習・進捗から外した。
- 旧分野の学習履歴・登録教材は**削除も書き換えもしない**（バックアップには含まれる）。画面向けのAPI（`/api/history`・`/api/registered-items`）が旧分野を返さず、おすすめ・集計も使わない。
- 一問一答の中分類「セキュリティ」（`lib/content/fields.js` の `security`）は、支援士・応用情報の出題分野であり旧分野の `security` とは別物。こちらは残している。
- 旧「AI の新着」（`/api/ai-feed`）と、AI レポート・論文の一覧は画面・APIから外した。データ（`lib/content/ai-readings.js` など）と週次更新スクリプトは残している（下の「未対応・要判断」を参照）。

## AWS コース（すべて「問題を見る → 思い出す → 答えを見る → 覚えていた／覚えていない」）

| コース | 試験名 | 現行の試験コード | 問題数 | 領域別の問題数（公式の配分） |
|---|---|---|---|---|
| 基礎 | AWS Certified Cloud Practitioner | CLF-C02 | 38 | クラウドの概念 8（24%）/ セキュリティとコンプライアンス 12（30%）/ クラウドテクノロジーとサービス 14（34%）/ 請求・料金・サポート 4（12%） |
| 設計・中級 | AWS Certified Solutions Architect - Associate | SAA-C03 | 40 | セキュア 12（30%）/ 回復性 10（26%）/ 高パフォーマンス 10（24%）/ コスト最適化 8（20%） |
| 設計・上級 | AWS Certified Solutions Architect - Professional | SAP-C02 | 32 | 組織の複雑さ 8（26%）/ 新規ソリューション 9（29%）/ 継続的改善 8（25%）/ 移行とモダナイゼーション 7（20%） |

- 試験名・試験コード・領域の配分は、AWS公式の試験ガイド（`docs.aws.amazon.com/aws-certification`）で確認した（2026-10-22）。
- **SAP は次期試験 SAP-C03 が公式ページで予告されている**が、現行は SAP-C02。問題は現行の SAP-C02 のガイドに基づく。CloudOps／旧 SysOps Administrator は SAA とは別の試験であり、含めていない。
- 問題は日本語のオリジナルで、試験問題・市販問題集の転載ではない。「公式問題」とは表示しない。本番試験の形式や合格を保証するものではない。
- SAA／SAP は、サービス名を答える問題に加え、短い状況に対する設計判断・トレードオフを答える問題（`kind: scenario`）が7割以上。
- 料金や上限などの変わりやすい値の丸暗記には偏らせていない。サポートプラン・サービス名の変更が進んでいる項目（例: Trusted Advisor のプラン、Application Migration Service → AWS Transform MGN）は、その旨を解説に書くか出題を避けた。

## 問題データの形式

`lib/content/aws/*.js` の各行は `[id, 領域, 種別, テーマ, 問題, 正解, 理由・解説, 根拠URL]`。`index.js` が次の項目を持つカードに展開する。

`id`（`aws-<clf|saa|sap>-d<領域>-<番号>`で安定。IPA の問題IDと衝突しない）／`family: 'aws'`／`exam`（`aws-clf` など）／`course`／`examCode`／`field`・`domain`（出題領域）／`group`（弱点判定の単位）／`question`・`answer`・`explanation`／`url`（根拠のAWS公式URL）／`checkedAt`（確認日）／`kind`。

根拠URLはすべてAWS公式ドキュメントで、各問題の主張は該当ページの記述に沿うことを確認してから収録した。裏取りできなかった問題は収録していない。

## 記録・復習・進捗

- 「答えを見る」だけでは何も記録しない。自己判定（覚えていた／覚えていない）を選んだ問題だけが、カードごとの進捗（間隔反復）と学習記録に残る。
- AWS だけを解いた回の学習記録は分野 `aws`、`quizResult.courses` にコースを持つ。IPA の一問一答の集計（`all`）にAWSは混ざらない。
- 復習・弱点・進捗はコース別（`aws-clf`／`aws-saa`／`aws-sap`）と領域別。弱点は「5回以上解いて覚えていた割合が7割未満の領域」。
- `/api/quiz/deck` の `exam` は、`all`（IPA全体・従来どおり）／`aws`（AWS全コース）／`sc`・`ap`・`aws-clf`・`aws-saa`・`aws-sap`。
- 練習・再挑戦の「保存しない」経路、二重クリック・キー連打・保存失敗と再試行・中断のガードは、AWS でも同じ画面を使うため変わらない。

## 未対応・要判断

- 週次の読み物更新（`.github/workflows/update-content.yml`、`scripts/update-readings.js`）は、画面から外した旧データを更新し続ける。止めるかどうかはワークフロー設定の変更になるため、このブランチでは触れていない。
- AWS の問題はオフライン用の保存（最大60問）の対象外（IPAのみ）。
- 旧分野の履歴は画面から見えなくなる。確認したい場合は、設定のバックアップ（JSON）に含まれる。
