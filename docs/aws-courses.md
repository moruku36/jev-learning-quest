# AWSコースと旧分野の整理

この文書は2026-10-22のAWS 3コース追加時点の記録です。現在のAWS基礎AI・GCP追加分のコース一覧と公式ガイドは [資格別一問一答](cloud-courses.md) を参照してください。

## 変更の概要

- 分野は「ネットワーク（`nw`）」「支援士（`sc`）」「AWS（`aws`）」。旧分野の AI（`ai`）・クラウド（`cloud`）・セキュリティ（`security`）は、学習画面の分野一覧・読み物・おすすめ・復習・進捗から外した。
- 旧分野の学習履歴・登録教材は**削除も書き換えもしない**（バックアップには含まれる）。画面向けのAPI（`/api/history`・`/api/registered-items`）が旧分野を返さず、おすすめ・集計も使わない。
- 一問一答の中分類「セキュリティ」（`lib/content/fields.js` の `security`）は、支援士・応用情報の出題分野であり旧分野の `security` とは別物。こちらは残している。
- 旧「AI の新着」（`/api/ai-feed`）と、AI レポート・論文の一覧は画面・APIから外した。データ（`lib/content/ai-readings.js` など）と週次更新スクリプトは残している（下の「未対応・要判断」を参照）。

## AWS コース（すべて「問題を見る → 思い出す → 答えを見る → 覚えていた／覚えていない」）

| コース | 試験名 | 現行の試験コード | 問題数 | 領域別の問題数（公式の配分） |
|---|---|---|---|---|
| 基礎 | AWS Certified Cloud Practitioner | CLF-C02 | 39 | クラウドの概念 8（24%）/ セキュリティとコンプライアンス 12（30%）/ クラウドテクノロジーとサービス 14（34%）/ 請求・料金・サポート 5（12%） |
| 設計・中級 | AWS Certified Solutions Architect - Associate | SAA-C03 | 34 | セキュア 10（30%）/ 回復性 10（26%）/ 高パフォーマンス 8（24%）/ コスト最適化 6（20%） |
| 設計・上級 | AWS Certified Solutions Architect - Professional | SAP-C02 | 30 | 組織の複雑さ 7（26%）/ 新規ソリューション 9（29%）/ 継続的改善 7（25%）/ 移行とモダナイゼーション 7（20%） |

- 試験名・試験コード・領域の配分は、AWS公式の試験ガイド（`docs.aws.amazon.com/aws-certification`）を、このコミットの作業時（2026-10-22）にあらためて取得して確認した。
- **SAP は次期試験 SAP-C03 が公式ページで予告されている**。公式ページ（`aws.amazon.com/certification/certified-solutions-architect-professional/`、2026-10-22 取得）の記載は「現行 SAP-C02 の最終受験日は 2026年11月16日」「更新版 SAP-C03 の登録開始は 2026年10月27日」で、SAP-C03 の受験開始日やベータの日付は記載されていないため**未確認**。現行は SAP-C02 のため、問題は現行の試験ガイドの領域に沿って作った。CloudOps／旧 SysOps Administrator は SAA とは別の試験であり、含めていない。
- 問題は日本語のオリジナルで、試験問題・市販問題集の転載ではない。「公式問題」とは表示しない。本番試験の形式や合格を保証するものではない。
- **SAA／SAP の水準について**: 短い状況つきで、当てはまるサービス・構成を選ぶ想起問題が中心（`kind: scenario`）。SAP は上級試験の領域に沿った主要サービスの使い分けと基本設計の想起であり、複数サービスの組み合わせやトレードオフを深く問う本番形式の設計演習ではない。解答に必要な前提（障害の範囲・RTO/RPO・DBエンジン・許容するアプリ改修など）は問題文に明示し、前提が違うと答えが変わる問題は、解説で代替案を示す。
- 料金や上限などの変わりやすい値の丸暗記には偏らせていない。解説で数値に触れるものは、数値の暗記に依存しない形にした。サポートプラン・サービス名の変更が進んでいる項目（例: Trusted Advisor のプラン、AWS Transform MGN）は、その旨を解説に書くか出題を避けた。

## 問題データの形式

`lib/content/aws/*.js` の各行は `[id, 領域, 種別, テーマ, 問題, 正解, 理由・解説, 根拠URL（または配列）]`。`index.js` が次の項目を持つカードに展開する。

`id`（`aws-<clf|saa|sap>-d<領域>-<番号>`で安定。**欠番は詰めない**ので、削除しても学習済みの問題のIDは変わらない。IPA の問題IDと衝突しない）／`family: 'aws'`／`exam`（`aws-clf` など）／`course`／`examCode`／`field`・`domain`（出題領域）／`group`（弱点判定の単位）／`question`・`answer`・`explanation`／`url`（主な根拠）・`sources`（根拠の一覧）／`sourceKind`（`docs`＝公式ドキュメント、`site`＝公式サイト。画面の表記を分ける）／`checkedAt`（確認日）／`kind`。

## 根拠の確認（2026-10-22）

- 各問題の「答え」と「解説」を、作業者が取得した根拠ページの本文に照らして、記述と矛盾せず支えられる範囲に収めた。URLの取得やキーワードの一致だけでは判断していない。ただし、逐語の照合や、ページ全体の文脈・最新版との差までの網羅的な検証ではなく、第三者による検証でもない。公式の記述は変わり得るため、確認日（2026-10-22）を付けている。
- 本文で支えられない主張は、解説から外すか、支える公式ページを追加した（例: Cost Explorer の説明を Budgets のページに置いていた問題を、Budgets と Cost Explorer の2問に分けた）。
- 数値が条件つきだったもの（Aurora のボリューム上限＝エンジンのバージョンで異なる、移行戦略の「90日」、Cost Explorer の「13か月」、Glacier Deep Archive の最小保管期間）は、数値に依存しない問題・解説にした。
- 近似重複は、同じ事実を同じ向きで問うものを外した（問題数維持のための水増しはしない）。外したのは SAA 6問（セキュリティグループとNACL、EFS、CloudFront、S3エンドポイントのコスト、DirectConnectとVPN、Secrets Manager）と SAP 2問（コスト配分タグ、Secrets Manager）。一方、Cost Explorer は別の事実として1問追加した。結果は 110問 → 103問（基礎39・SAA34・SAP30）。
- 外した問題は出題に残していない。本文で支えられないと判断した主張は、解説から外すか、支える公式ページを追加した。VPN と Athena の問題は、取得した本文に合わせて根拠ページを追加し、本文に書かれていない主張（VPNがインターネットを通ること）は載せていない。

## 記録・復習・進捗

- 「答えを見る」だけでは何も記録しない。自己判定（覚えていた／覚えていない）を選んだ問題だけが、カードごとの進捗（間隔反復）と学習記録に残る。
- AWS だけを解いた回の学習記録は分野 `aws`、`quizResult.courses` にコースを持つ。IPA の一問一答の集計（`all`）にAWSは混ざらない。
- 復習・弱点・進捗はコース別（`aws-clf`／`aws-saa`／`aws-sap`）と領域別。弱点は「5回以上解いて覚えていた割合が7割未満の領域」。
- `/api/quiz/deck` の `exam` は、`all`（IPA全体・従来どおり）／`aws`（AWS全コース）／`sc`・`ap`・`aws-clf`・`aws-saa`・`aws-sap`。
- 練習・再挑戦の「保存しない」経路、二重クリック・キー連打・保存失敗と再試行・中断のガードは、AWS でも同じ画面を使うため変わらない。

## オフライン

- AWS の問題は、オフライン用の保存（最大60問）の**対象外**（IPA のみ）。今回、AWSのオフライン対応は新設していない。
- オフラインでAWSの演習・復習・弱点を開くと、「問題がない」「弱点がない」とは表示せず、「AWSの問題はオフラインでは使えません。オンラインに接続してからもう一度開いてください」と表示する。通信失敗でオフラインに切り替わった場合も同じ。オフラインのバナーと、試験問題タブのAWSカードにも明記している。
- オンラインに戻れば、通常どおり出題される（`test_quiz_guard.js` の合成テストで確認）。

## 未対応・要判断

- 週次の読み物更新（`.github/workflows/update-content.yml`、`scripts/update-readings.js`）は 2026-10-22 に停止した（schedule を外し手動実行のみ、GitHub Actions 上も無効化）。
- 旧分野の履歴は画面から見えなくなる。確認したい場合は、設定のバックアップ（JSON）に含まれる。
